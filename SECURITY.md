# Security Policy

## Supported versions

Clean My Codex is currently in a testing stage. Security fixes are provided for the latest release only. Please reproduce an issue with the latest release before reporting it when doing so is safe.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include sensitive Codex data in a report.

Use GitHub's private vulnerability reporting from the repository's **Security** tab, or open a [private security advisory](https://github.com/FinnaXxx/CleanMyCodex/security/advisories/new). Include the affected version, platform, impact and minimal reproduction steps. Redact credentials, session contents, thread IDs, usernames and local paths.

The maintainer will acknowledge a report when it has been reviewed and will coordinate disclosure after a fix is available. No response-time guarantee is made while the project remains in testing.

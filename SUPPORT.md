# Support

Clean My Codex is a community-maintained project in a testing stage.

- Use [GitHub Issues](https://github.com/FinnaXxx/CleanMyCodex/issues) for reproducible bugs and feature proposals.
- Include the Clean My Codex version, platform, Codex version and relevant steps. Redact usernames, local paths, thread IDs and session contents from logs and screenshots.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

Support is best-effort; no response or compatibility guarantee is provided.
